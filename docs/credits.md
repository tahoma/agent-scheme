# Project Credits

This document records project authorship, maintenance, and tool-assisted
development attribution for Consent Scheme. It is intentionally separate from
Git commit trailers: trailers identify people who authored a particular commit,
while this document records durable project-level credit and policy.

## Human Authors and Maintainers

- Tahoma Toelkes — project creator, maintainer, and copyright holder.

Human contributors remain credited through the Git history, issue and pull
request records, SPDX metadata where applicable, and ordinary project
acknowledgment. A `Co-Authored-By` trailer is appropriate when it names a human
co-author who shares authorship responsibility for a commit.

## Agentic Development Tools

Consent Scheme has used tool-assisted drafting, editing, search, verification,
and review while remaining a human-authored project. The following tools are
credited for project-level development assistance:

- Codex — repository navigation, patch drafting and editing, command
  orchestration, verification, issue and pull request workflow support, and
  review assistance under maintainer direction.
- Claude Code — repository navigation, patch drafting and editing,
  verification, issue and pull request workflow support, and review assistance
  under maintainer direction.

These tools are credited as development aids, not as authors, maintainers,
copyright holders, or accountable project participants.

Tool-assisted work must pass through ordinary maintainer judgment before it is
accepted. The human contributor who submits or lands a change remains
responsible for its design, licensing, tests, and long-term project fit.

## Attribution Policy

Commit trailers should identify accountable human collaborators. Do not use a
`Co-Authored-By` trailer to credit automated tool assistance, model output, local
automation, editor integrations, or hosted coding services. Credit that category
of assistance here instead.

Do not remove legitimate human co-author trailers. When older published history
contains automated-tool co-author trailers, the project may rewrite those
specific trailers out while preserving commit content and ordinary
commit-message substance. Coordinate that rewrite before force-pushing so active
branches and pull requests can be rebased or recreated safely.

Repository contributor displays are a hosting-service view over commit metadata,
not the canonical project credits list. After any coordinated attribution
rewrite, verify that the public contributor display reflects human project
participation rather than automated-tool trailer metadata.
