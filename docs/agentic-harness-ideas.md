# Agentic-Harness and Language-Agent Prior-Art Synthesis

This document synthesizes the external prior art curated under
[Scheme References → Agentic Harness and Language-Agent References](references.md#agentic-harness-and-language-agent-references)
into a project-grounded idea bank for the Milestone M2 *REPL Agent Harness* work
(Chunk 0.17). It reads each reference through Consent Scheme's distinctive stance
— Lisp-first internal data, the REPL as a shared agent action space, explicit
host capabilities with consent gating, append-only inspectable state, a
deterministic loop around nondeterministic model output, cross-host parity, and
bounded execution of untrusted code — and turns each paper's mechanism into
concrete experiments, features, and design decisions.

**Status: non-normative.** This is exploration and grounding, not committed
design. It is prior art turned into options; the binding decisions stay in the
project's own design docs — chiefly
[Task Lifecycle and Control Loop](control-loop.md) and the *Agent Layer* section
of [Architecture and Threat Model](architecture.md). Where this synthesis and a
design doc disagree, the design doc wins. Roadmap tags below use **M2** for the
Chunk 0.17 thesis work and *later* for a named follow-on chunk; effort is a rough
**S/M/L**. Source references are cited inline by short key (for example
`[CodeAct]`, `[tau-bench]`), each resolving to an entry in
[references.md](references.md#agentic-harness-and-language-agent-references).

## 1. Framing: the throughline, and where we sit

Read together, these references share one structural shape: an LLM agent is a loop that *perceives, reasons, acts, and remembers*, and nearly every paper's headline mechanism is "the model autonomously does X" — writes its own memory [MemGPT, Generative-Agents], prunes its own search branch [ToT], marks its own test passed [Reflexion, Voyager], runs the code it wrote [CodeAct, AutoGen], decides who speaks next [AutoGen], declares the task finished [ReAct], or sets its own salience that steers future context [Generative-Agents]. The field's default is to let nondeterministic model output **drive control, authorize success, and mutate state in place, over a JSON wire, on a single runtime**, then report results as means over noisy runs.

Consent's distinctive move is one inversion applied uniformly: **demote each of those autonomous acts to a *proposal datum* that a deterministic, policy-owning loop adjudicates.** Because the proposal is a printable Scheme form, the adjudication becomes inspectable, replayable, and cross-host-checkable. Our seven commitments line up against the field's seven defaults: Lisp-first datums (vs. JSON-as-truth), REPL-as-shared-action-space (vs. opaque orchestration), capability/consent gating (vs. free-form effects), append-only inspectable state (vs. in-place mutation), a deterministic loop around nondeterministic output (vs. model-driven control), cross-host parity (vs. single-runtime means), and bounded-against-untrusted-code (vs. assumed-free compute). The payoff is that each paper's mechanism, re-expressed on our runtime, becomes an *artifact* — and several of them become benchmarks no existing framework can even pose, because they require a redaction layer, a deterministic verifier, or two independent cores agreeing on a byte stream.

The rest of this report turns that into an idea bank, by runtime area, with roadmap fit (M2 = the 0.17 thesis chunk; *later* = a named follow-on chunk) and rough effort (S/M/L).

## 2. Idea catalog by runtime area

### 2.1 Control loop (state machine, receipts, planning sub-steps)

- **Three-channel transcript records: `perception` / `cognition` / `action`, with cognition structurally distinct from action.** A cognition datum can never carry a grant; an action datum always references the policy decision that authorized it. The "proposes-never-authorizes" rule becomes a record-shape invariant at the loop boundary. [Rise-of-Agents], [ReAct], [CoALA] — *M2, M, very high leverage.*
- **Typed `agent-thought` record with a closed role enum** (decompose-goal / track-progress / extract-fact / handle-exception / reformulate-action / synthesize-answer), required as input to `agent-decision`, with a prose-with-role-tag escape hatch so unclassified reasoning never goes opaque. Stops `reason` from being free prose. [ReAct] + [CoALA] — *M2, M, high.*
- **Decision cycle as three recorded sub-steps: `agent-proposal-set` → `agent-evaluation` (with provenance: heuristic vs model-value vs rule) → `agent-decision`.** Today the loop jumps from planning to a single selected action; the evaluation artifact is missing, so a replay driver can't re-score the candidate set. [CoALA], [ToT], [Wang-survey] — *M2, M, high.*
- **`plan-revision` as an append-only causal chain** (old-step-id → new-step-id + triggering observation), not in-place mutation; `plan-step-status!` becomes one recorded case. [Wang-survey], [ReAct] — *M2, S, high (cheap, strong inspectability payoff).*
- **Deterministic repetitive-loop detector** as a stop condition: fingerprint each (thought-role, action, observation) by `equal?` on canonical datums; N identical cycles or a step ceiling → `repeated-failed-action` receipt citing the offending datums. ReAct attributes 47% of failures to non-recovering loops; Reflexion triggers at >3 cycles / >30 steps. [ReAct], [Reflexion] — *M2, S, high (the runner needs it anyway).*
- **`finish`/terminal-action split:** the model proposes `(action finish ...)`, but `complete` requires the verifier gate. The most consequential transition for the core invariant. [ReAct], [SWE-bench], [Voyager] — *M2, M, very high.*
- **Non-informative-observation guard:** classify each observation informative vs non-informative (empty / unchanged / duplicate-by-serialized-equality); a run of non-informative obs forces a reformulate-action thought or `insufficient-evidence`. Detectable only because observations are comparable datums. ReAct: 23% of failures. [ReAct] — *M2, S, medium-high.*
- **Explicit empty-observation datum** `(agent-observation (kind empty) (value (ran-ok no-output)))`, removing the "no observation captured" vs "observed nothing" resync ambiguity. [SWE-agent] — *M2, S, medium.*
- **`iteration-limit` stop reason / `max-loop-turns` charged per cycle** (distinct from allocation-charged value budget) — a coarse, model-independent kill-switch whose receipt records turns-used. [Building-Effective-Agents] — *M2, S, medium-high.*
- **Workflow-vs-agent `authority-mode` field** on every task/plan: `workflow` = pre-committed action sequence the loop refuses to deviate from (replay proves byte-reproducibility); `agent` = model may choose next action. Turns an architecture-diagram label into an enforceable mode. [Building-Effective-Agents] — *M2, M, high.*
- **Backtracking as a first-class transition with a receipt** `(backtrack (from …) (to …) (reason impossible))` that accounts for grants acquired on the pruned branch. Sound only over pure-Scheme subtrees. [ToT] — *later (planning-hardening, gated on a search driver), M, high.*
- **`interface-rejected-action` stop/pause reason** when the agent repeatedly proposes reader-rejected edits or out-of-surface actions — makes "the interface, not the model, stopped this" an inspectable diagnostic. [SWE-agent] — *M2, S, medium.*

### 2.2 Capability / consent gating (authority boundary, AST admission, attenuation)

- **Effect classification on each agent-action** `kind ∈ {reasoning, retrieval, semantic-write, episodic-write, procedural-write, grounding}`, with a hard invariant that `procedural-write` and `grounding` can never be self-authorized by model output; reasoning/retrieval run as pure helpers under budget, no gate. CoALA treats all writes uniformly; we make the procedural-write/grounding boundary a hard authority boundary. [CoALA] — *M2, M, very high.*
- **AST subtree verifier as a pre-authorization gate.** Because the action space is already executable Scheme datums, "parse the call into an AST" is free — the proposed form *is* the AST. Accept a call only if it is a subtree of a registered capability signature (required args matched, defaulted optionals skipped); else `(capability-decision … (reason hallucinated-binding))`, fail-closed. Gorilla's hardest mechanism is nearly free here. [Gorilla] — *M2, M, very high.*
- **Three-way typed failure condition: `hallucinated-tool` (structure) vs `misapplied-tool` (real binding, arity/type/constraint mismatch) vs `unauthorized-tool` (real, well-formed, policy-denied).** Three different gates, three different receipts. The unauthorized arm already exists. [Gorilla], [tau-bench] — *M2, S, high.*
- **Sub-expression-granularity gating inside one composed code action**, with mid-form pause: per-call `capability-decision` datums, the loop pausing at exactly the gated call (`task-pause` referencing the unevaluated tail) and resuming live bindings after approval. The irreducible tension CodeAct creates; a Python+JSON framework cannot do this cleanly. [CodeAct] — *M2 (single gated call); later consent-hardening (deep partial-eval resume), L, very high — hardest item, stage it.*
- **Edit-with-lint as a policy gate, not a tool convenience.** A mutate-via-edit request carries proposed text; the runtime parses it with the existing reader; the verifier sets `verifier-result` *before* `capability-decision` can reach `approved`; a reader-rejected edit → `(capability-decision (status denied) (reason syntax-invalid))`. The parser that gates the write is the reader the runtime already trusts. [SWE-agent] — *M2 (hook); later (full edit-gate), M, high.*
- **MCP tool annotations/descriptions as tainted, advisory-only data.** A tainted-datum wrapper strips any field claiming a verifier passed, a route, a grant, or reduced consent; `readOnly`/`destructive` annotations are rule input, never authority. Adversarial-annotation fixtures assert the gate still requires `approval-resolve!`. Bake in from the start of the import path. [MCP], [Building-Effective-Agents] — *M2, S, high (a missed default here is a security hole).*
- **MCP roots as monotonic capability-attenuation** — a grant carries `file://` boundaries; `grant-attenuate` only narrows; path-traversal rejection. [MCP] — *later (needs host fs adapter; datum model at M2), M, high.*
- **Constraint-aware selection as a policy-checkable predicate** distinct from the structure check: signatures carry `(constraints (max-cost cheap) (effect read-only) (scope (project-root)))`; arbitration rejects a call whose constraints aren't satisfied → `(capability-decision (status denied) (reason constraint-unmet))`. [Gorilla] — *M2 (effect/scope); later (cost/budget), M, medium-high.*
- **`agent-action-space` verb / authority-accurate generated tool docs:** enumerate the capability-requests reachable from the current policy, returning canonical datums (each tool + its required grant); generate the prompt's action-grammar reference *from the grants the env actually holds*, so documented and permitted action spaces cannot drift. [Rise-of-Agents], [SWE-agent], [Toolformer] — *M2, M, high.*
- **Conversable-agent capabilities = a list of grants, not an agent class.** Capability presence (not subclass) decides authority; an agent with no tool-exec grant can propose forms but cannot run them. [AutoGen] — *M2, M, high.*

### 2.3 REPL action space (CodeAct/SWE-agent thesis, native)

- **Model output is a *quoted proposal datum*, never `eval`'d as raw authority.** The model emits a candidate form inside `(agent-action (kind code-action) …)`; the loop READS it, walks it for capability requests, runs it under policy. A fixture where the proposed form tries to mint a grant / resolve an approval / call `buffer-save!` asserts the loop quarantines it to a `capability-decision`. The load-bearing safety boundary for the whole code-action space. [CodeAct] — *M2, M, very high — non-negotiable foundation.*
- **Native tool chaining via nested Scheme forms** `(translate (wiki-search q) 'en)` — one gated evaluation, each inner host call hits the gate in evaluation order. The CodeAct payoff over per-call JSON, and it collapses Toolformer's call-wording fragility into one reader-normalized datum. [Toolformer], [CodeAct] — *M2, S, high.*
- **Traceback-as-observation via condition/restart datums** (not flattened strings), feeding self-correction, bounded by `repeated-failed-action`. [CodeAct], [Voyager] — *M2, M, high.*
- **Windowed-viewer / summarized-search / poka-yoke verbs as the ACI on the REPL.** `(host file view path)` returns `(window (start N)(end M)(total T)(more #t))` — the window IS the datum and doubles as capability attenuation; `(host search …)` returns a bounded `search-result` tied to existing value-render limits; descriptors carry Scheme predicates (require-absolute-path) evaluated in the same fail-closed gate. [SWE-agent], [Building-Effective-Agents] — *M2 (minimal read-only window + descriptor); later (full surface), M, high.*
- **UserProxyAgent code extraction via the reader, not markdown grep.** A model reply is a datum; the existing reader (with reader-recovery as data) extracts forms; a malformed proposal yields a condition datum. [AutoGen] — *M2, M, high.*
- **Structural code-action turn fixture proving fewer turns** than a JSON-style baseline for the same goal (strict turn-count assertion). Encodes CodeAct's ~30%-fewer-turns result as a diff of two transcript streams. [CodeAct], [SWE-bench], [GAIA] — *M2, M, medium-high.*
- **Transparency-for-free:** a `plan-rationale` field the planner must populate, rendered in REPL chrome at observing→planning. No separate "show your work" channel — the action space *is* the shared session. [Building-Effective-Agents] — *M2, S, medium-high.*
- **ToT thoughts as evaluable Scheme forms** so state evaluation is real in-runtime lookahead (e.g. Game-of-24 arithmetic computed deterministically), not an LM guess. [ToT], [CodeAct] — *M2, M, medium-high (most valuable once a search driver exists).*

### 2.4 Memory & reflection (taxonomy, retrieval, append-only invariant)

The largest cluster, and the one with the sharpest unanimous tension: every paper mutates/overwrites/evicts memory; our invariant is append-only, inspectable, replayable. The consistent answer across all of them: *reflection, eviction, consolidation, recency, and "forgetting" all become new appended datums with provenance/supersedes links and tombstone/archive receipts — never in-place edits.*

- **Four CoALA memory classes as a `memory-class` field** on one record stream (working / episodic / semantic / procedural). Episodic = read-only projections of the transcript; semantic = current put!/add! datums; procedural = skill/decision-procedure refs. Unifies with Wang's profile/memory/plan/action map. [CoALA], [Wang-survey], [MemGPT] — *M2 (procedural hardening defers), M, very high.*
- **Append-only gated reflection:** `task-reflection` / synthesis datums written only on `failed` terminal receipts; the model authors text but a deterministic loop step admits it; insight nodes carry `(cites <base-id> …)` edges and never overwrite base observations. Replay invariant: re-running synthesis over the recorded base stream + recorded model output reproduces identical insight nodes (model output replayed, not re-sampled). The unanimous reconciliation of self-criticism with append-only memory. [Reflexion], [Generative-Agents], [Wang-survey], [CoALA] — *M2 (shape + gate); later (full author behavior), M, very high.*
- **Deterministic, inspectable retrieval with a `memory-selection` receipt.** Rank by an all-Scheme weighted sum (recency exp-decay + importance + relevance, each a rational datum; weights a printable retrieval-policy record); emit per-candidate sub-scores and the cutoff. Relevance starts as tag/keyword overlap; embeddings, if ever used, are a rebuildable untrusted advisory cache, never the source of truth. [Wang-survey], [Generative-Agents], [Reflexion] — *M2, M, very high.*
- **Importance/poignancy as proposed-then-gated** `(importance (proposed . N)(effective . M)(source . model|rule|policy))`; policy sets `effective`. A salience score is authority over future context, so it is gated and provenance-stamped like a grant. [Generative-Agents] — *M2, M, high.*
- **MemGPT-style memory-pressure paging owned by the loop, driven by the token ledger.** At a warning watermark, emit `(memory-pressure-warning …)`; at flush, route the FIFO to the summarizer role and replace evicted events with `(recursive-summary …)` (evicted events preserved in recall storage for exact prompt reconstruction). The summarizer *proposes*; the loop *owns* eviction policy. [MemGPT] — *M2 (stub vs fake token counts); later (real watermarks), M, high.*
- **Two-tier working-context / archival split as append-only `(agent memory)` + `(agent context)` verbs.** Small in-context working set over an append-only archival store; promotion is a curator-role proposal, demotion drops the reference, never deletes. [MemGPT], [CoALA] — *M2 (shapes); later (curator promotion), M, high.*
- **Context assembly as a first-class replayable `(context-build …)` artifact** naming exactly which system-instruction, working-context facts, FIFO window, plan, and observation datums (with per-region token costs) went into a given `model-provider-request`. Answers "why did the model see X but not Y" from the transcript alone. [MemGPT] — *M2, M, high.*
- **Episodic-recall helper over the transcript stream** (`memory-find`/`recall` returning prior task-stop/pause receipts with matching goals + stop-reasons) so the planner avoids known-bad trajectories — a pure helper, no gate. Episodic memory *is* the replayable transcript. [CoALA], [Reflexion] — *M2, S, high.*
- **Append-only eviction/consolidation as derived views:** `(memory-consolidation …)` links duplicates to a merged abstract (both retained); `(memory-eviction …)` is a tombstone/archive receipt, never a delete; recency is an appended `(memory-access <id> <tick>)` event on the loop's logical clock — removing the papers' only destructive edit. [Wang-survey], [MemGPT], [Generative-Agents] — *later (persistence/resume; principle fixed M2), M, high.*
- **Scope-and-redaction-aware retrieval guard:** filter candidates by the requesting context's scope (instance/session/project) and run redaction *before* any record enters a prompt, so ranking score can never smuggle a redacted/local-only memory into a lower-trust call. [Generative-Agents], [MemGPT] — *M2, M, high.*
- **Naming hygiene:** disambiguate model-driven memory synthesis (`(memory synthesize)` / `(agent recall)`) from the privileged `(agent reflect)` host-introspection verb; document in `docs/feature-reflection.md`. [Wang-survey], [Generative-Agents] — *M2, S, medium-high (prevents an authority confusion lexically).*
- **Memory-write / reflection-trial / importance budgets,** charged at allocation, with distinct stop reasons (`memory-write-budget-exhausted`, `reflection-budget`). Unbounded agent memory is an attack/cost surface. [CoALA], [Reflexion], [Generative-Agents] — *later (budget-hardening; thread the shape M2), S, medium-high.*

### 2.5 Transcripts / replay (session-as-artifact, resync, thought-editing)

- **Three-channel transcript records with resync attributing any tick to its channel** (cross-listed with §2.1 — it is both a loop encoding and a replay contract). [Rise-of-Agents] — *M2, M, very high.*
- **`thought-edit` replay operation:** load a recorded transcript, replace one `agent-thought` datum, re-run from that step under `deterministic-pure`; host effects after the edit stay `recorded-observation` unless a fresh grant is issued. Modeled as a *fork*, not in-place mutation. The flagship "replay as a safety primitive" demo. [ReAct] — *later (persistence/resume + replay-hardening; records land M2), L, high.*
- **Counterfactual-replay tool-call usefulness verifier** (Toolformer's loss-reduction filter, logit-free): compare the recorded next decision against a counterfactual replay where one observation is withheld; emit `(tool-call-utility (call …)(delta …)(kept #t/#f))`. [Toolformer] — *later (needs mature replay), L, high.*
- **Retrieval-sensitivity replay experiment** (Gorilla's RAT finding): replay the same stubbed model under none / wrong-doc / oracle grounding, assert functional-match and hallucination move oracle > none > wrong. Turns a headline finding into a deterministic regression test. [Gorilla] — *later (needs retrieval-as-capability), M, medium-high.*
- **Verdict-transition / fault-attribution audit datums.** Record per-form `{fail-before, pass-after}` / `{pass-before, pass-after}`; treat PASS_TO_PASS regression as a distinct named verdict; auto-classify failed reruns by inspecting the transcript. The papers did this as manual studies of ~36 trajectories; here it is a pure function over the record stream. [SWE-bench], [tau-bench] — *M2 (tables, S); later (classifier, M), high.*
- **`request_heartbeat`/continue-vs-yield as a budget-charged, receipted step.** The loop honors `continue` only while step/heartbeat budgets allow, else forces yield with `heartbeat-budget-exhausted`. [MemGPT] — *M2, S, medium-high.*

### 2.6 Eval budgets & bounding untrusted code

The papers assume free compute (ToT's b·k·T, MemGPT's heartbeat, Reflexion's retries, Voyager's refinement, CodeAct's loops); our answer is uniform — *charge it, bound it, emit an explaining receipt.*

- **Budget-exhausted receipt fires deterministically mid-composed-action, cross-host.** A fixture where an agent-emitted form contains an unbounded loop asserts the allocation-charged step budget halts it with a `budget-exhausted` receipt pointing at the partial transcript, byte-identical on both cores. Turns "untrusted code as the action space" into a bounded, replayable property. [CodeAct] — *M2, M, very high.*
- **Per-tool invocation-cost field charged at call time** (pure → eval budget; host → +host-call cost; provider-backed → +tokens); the gate refuses a call exceeding remaining budget. Closes a gap Toolformer left open. [Toolformer], [Gorilla], [tau-bench] — *M2 (field); later (charging), S, high.*
- **Tree-search budget** (node-expansions, model-eval-calls, max-frontier-width, max-depth) folded into the cumulative ledger; the receipt explains why with the best partial node found. [ToT] — *M2 (primitives); later (full record), M, high (tied to the search driver).*
- **Sampling-budget guard for MCP server-initiated recursive `createMessage`,** charged at allocation, requiring approval of the call *and* the exact prompt datum *and* the result-visibility scope. [MCP] — *later (provider/budget-hardening), M, high.*
- **Self-generated verifier tests as pure budgeted Scheme** (bounded reader, structure-validated, capped at K, run as pure helpers, no grant); a self-test passing is *evidence the policy weighs*, never automatic completion (mitigating Reflexion's false-positive risk). [Reflexion] — *later (needs real model output; substrate exists now), M, high.*
- **Datum-level structured patch application under the eval/intern-table budget,** emitting `(patch-conflict …)` on apply failure. The Lisp-first counterpart to text diffs — no fuzzy-match nondeterminism. [SWE-bench] — *M2, L, high.*
- **Recursion/abandon bounding for Voyager-style refinement** with an explaining receipt ("abandoned after N refinements, last condition = <datum>, charged <budget>"). [Voyager] — *M2 (budgets+loop); later (bounded-abandon proof), M, medium-high.*

### 2.7 Providers & tool-calling

Unanimous tension: JSON-schema tool defs are the wire edge only; the source of truth is Scheme.

- **Tool specs derived from existing docstring-metadata vectors, not hand-written schemas.** The `#((parameters …)(returns …)(effects …))` blocks generate the wire schema, the in-context example, *and* drive the gate (the `effects` field tells the gate pure-under-budget vs capability-request). Schema, example, and helper can never drift. [Toolformer], [Gorilla], [SWE-agent] — *M2, M, very high (the M2 tool-calling deliverable).*
- **Decode-time interrupt/execute/resume as a receipt-carrying loop primitive.** A mid-stream tool-call proposal → acting transitions to waiting-for-host with a `task-pause` naming the call, runs the gate, executes, records the observation, resumes — making the un-gated splice impossible. [Toolformer] — *M2, M, high.*
- **MCP accept/decline/cancel ↔ approval-status codec** (accept→approved, decline→denied, cancel→canceled) with the approval store as source of truth; content payload rides as a datum on the resolved approval. Proves MCP is a wire encoding over canonical approval datums. [MCP] — *M2, S, high.*
- **MCP form-mode elicitation as a control-loop pause** (observing→waiting-for-approval, pause receipt embeds the requestedSchema as a datum, blocks until `approval-resolve!` supplies a schema-validated content datum). A first-class loop state with a replayable receipt vs an ad-hoc callback. [MCP] — *M2 (pause/resume); later (schema-validation hardening), M, high.*
- **Call-wording-invariance fixture** proving syntactically different calls collapse to one reader-normalized `agent-action` datum. Turns Toolformer's wording fragility into a structural advantage. [Toolformer] — *M2, S, medium-high.*
- **Deterministic provider-routing escalation (ReAct↔CoT-SC backoff)** triggered by the step-budget boundary, recorded as `model-routing-decision` data; consensus by a deterministic Scheme aggregator over readable result datums, not model self-selection. [ReAct], [Building-Effective-Agents] — *later (provider/budget-hardening; trigger+records M2), L, medium-high.*
- **Sampling locus-of-control fix:** MCP server-initiated sampling re-cast as the server *proposing* a request that our loop and approval gate fully own — otherwise an external party pushes the loop into planning/acting. A correctness requirement, not an enhancement. [MCP] — *later (consent/provider-hardening), M, high.*
- **Typed JSON-RPC errors decode into the condition/restart datum family** (-32601, -32602, -32042), so a transport failure is a recoverable Scheme condition the replay driver resyncs past. [MCP] — *M2, S, medium-high.*
- **MCP URL-mode credential capture routed through redaction** (`context-local-only!`, fails `safe-for-provider?`); the credential handle is a grant whose value never enters transcript/memory/context. Note the deliberate exception: this credential state lives in a redacted, non-replayed side-channel. [MCP] — *later (provider/consent-hardening), M, high.*

### 2.8 Multi-agent / orchestration

Post-M2 (0.19+) usage, but the *datum formats* should be specced now. Unanimous reframing: multi-agent state lives in one shared, append-only, policy-gated transcript — not per-agent opaque buffers — so a debate is a replayable, parity-checkable artifact.

- **send/receive/generate_reply over the shared interaction-environment** — a message is an append to the one session transcript; multi-agent chat becomes a special case of the existing `(agent prompt / prompt-role)` verbs. [AutoGen], [Wang-survey] — *M2 (surface exists), M, high.*
- **GroupChatManager speaker selection as a deterministic `selecting-speaker` state** with a decision datum + receipt; selection may be model-proposed but the route is loop/policy-resolved. [AutoGen], [Wang-survey] — *later, L, high.*
- **Nested conversations as attenuated sub-sessions** (child inherits a strict capability subset; its transcript nests under the parent step; parent receipt aggregates the child's stop reason). Monotonic de-escalation of authority. [AutoGen] — *later, L, high.*
- **LLM user-simulator as a capability-attenuated peer agent** (NL-channel-only; denied all host capabilities; cannot observe the agent↔tool channel; `###STOP###` → a stop receipt). The information barrier is enforced by the consent layer, not prompt hygiene. Also the substrate for the entire tau-bench eval. [tau-bench] — *later (design the attenuation record now), L, high.*
- **interaction-mode session field** (instructor-executor vs equal-partnership) + `human_input_mode` (NEVER/TERMINATE/ALWAYS) and `max-consecutive-auto-reply` promoted to policy-governed approval/budget data with receipts (cap → `auto-reply-budget-exhausted`). [Rise-of-Agents], [AutoGen] — *M2, S, medium-high.*
- **Registered reply-functions as ordered `(trigger-predicate . reply-thunk)` records** (triggers run as pure helpers under budget; the chain is a printable datum). [AutoGen] — *M2, M, medium.*
- **Agent profile/personality record carrying a `capability-profile`,** binding "character" to authority; an LLM-generated profile is a proposal the gate must accept before it can widen the default posture. [Rise-of-Agents], [Wang-survey] — *M2, S/M, medium-high.*

### 2.9 Evaluation & benchmarks

The richest "Consent does what the paper cannot" cluster. **Cross-cutting principle: verifier authority is never proposable.** SWE-bench held-out tests, Voyager commit-on-verify, evaluator-optimizer, GAIA FINAL ANSWER, tau-bench r_action all converge on the same rule — the model PROPOSES (a patch, an answer, a skill, a critique), only a policy-side deterministic verifier stamps `verifier-passed`. **This is the single most important eval-theme idea and it is M2-now.**

- **Execution-verified task instance as a native loop terminator** (`fail-to-pass` acceptance + `pass-to-pass` regression partition; `complete` only when a replay applies the prediction and both partitions pass; else a receipt names the failing form). [SWE-bench] — *M2, M, very high.*
- **`pass^k` reliability metric decomposed by stop-receipt reason.** Rerun N times reseeding *only* model/user nondeterminism while holding policy/budgets/tool-transitions fixed; report pass^k = C(c,k)/C(n,k), sliced by `budget-exhausted` vs `policy-denied` vs `failed-verifier`. Isolates model flakiness from policy determinism — a separation only a deterministic-outer-loop runtime can make. [tau-bench] — *M2, M, very high.*
- **Two-tier policy ablation: gate-enforced authority rules vs advisory rules.** Run the suite with the advisory tier in/out, reporting the pass^1 delta; rules that DECIDE authority become hard gate predicates (un-ablatable by definition). tau-bench's central weakness (soft policy the model ignores) becomes a structural guarantee. [tau-bench] — *M2 (wiring); later (hardening), M, very high — the sharpest "stance beats the benchmark" result in the set.*
- **tau-bench outcome reward over replayed datums** (`r_action` = post-run DB datums vs goal-db via `consent-datum->external` canonical serialization, not `equal?`; `r_output` = required substrings present). Reward is a pure function over replayed datums; no Python harness. [tau-bench] — *M2, M, high.*
- **GAIA-style easy-to-verify fixture genre** `(gaia-task (goal …)(answer-type number|string|list)(answer …)(level …)(capabilities …)(files …))` + a pure-`(scheme base)` `consent-quasi-exact-match` verifier (number/string/list normalization as datum transforms, single-sourced, runs under budget, no capability). No model-as-judge. [GAIA] — *M2, M (fixture) / S (matcher), high.*
- **Output-redaction reward twist** (required substrings present AND forbidden substrings — e.g. full payment-method number — absent, over the replayed transcript). A framework with no redaction layer cannot pose this task. [tau-bench, extended] — *later (consent-hardening, on the M2 reward driver), S, high — uniquely Consent.*
- **Cross-host parity as the conformance spine for every corpus** (CoALA action-class; ReAct TAO incl. a repetitive-loop and a hallucinated-thought case; ToT Game-of-24; MemGPT paging; MCP session; AutoGen group-chat; Voyager skill-portability; tau-bench frozen-model replay) — all replayed on both cores and diffed via `make test-parity` by serialization. The project's signature claim. [all benchmark papers] — *M2 (seeds); later (growth), M per corpus, very high.*
- **SWE-bench three-stage admission filter as deterministic Scheme predicates** (attribute / test-relevant / execution-based; reject baseline-erroring fixtures as "unfixable-environment" by reading condition datums, not log strings). [SWE-bench] — *M2, S, medium-high.*
- **Mechanical task-uniqueness assertion** (stub the model to an oracle/enumerator; assert exactly one goal-db datum is reachable under the policy gate; reuse the parity gate as "two solvers agree"). The papers do this by laborious manual trajectory inspection. [tau-bench], [GAIA] — *M2 (alongside fixture format; CI gate later), M, medium-high.*
- **Declared-vs-actual capability/step audit** (GAIA difficulty stratification + contamination probe): derive `(level N)` from *measured* counts the transcript emits; with-file/without-file baseline confirms the task isn't solvable from memorized knowledge. "Did the agent actually use the tool" becomes a property of the consent log. [GAIA] — *later (after M2 file capabilities), M, medium-high.*
- **Bounded evaluator-optimizer** (model `reviewer` proposes findings; only a deterministic verifier's `verifier-result (status passed)` satisfies the stop; loop bounded by `repeated-failed-action`). The canonical M2 demonstration of model-proposes / verifier-disposes. [Building-Effective-Agents], [SWE-bench] — *M2, M, high.*

## 3. Cross-paper combination experiments

These are uniquely enabled by composing several references on our runtime — not deliverable from any single paper.

1. **Consent-Bench — policy-scored, replayable, dual-core agent benchmark.** [CodeAct]+[tau-bench]+[SWE-bench]+[GAIA]. The action space is gated Scheme in the shared REPL; the verdict dispatches on outcome type — held-out verifier forms (SWE-bench FAIL_TO_PASS/PASS_TO_PASS) vs final-DB-state equality (tau-bench r_action) vs quasi-exact-match on a factoid datum (GAIA); and a **fourth, uniquely-Consent axis** scores whether the trajectory *respected the policy gates* (every host write referenced a real grant, nothing bypassed redaction, no model output marked a verifier passed). The whole instance is one Scheme-readable record replayed on both cores under `make test-parity`. Reward is a pure function over the replayed datum stream — no model-as-judge. *Lands incrementally: single-verifier (GAIA/SWE-bench) fixtures M2; tau-bench DB-state and the policy-adherence axis in eval-hardening. Separates model flakiness from policy/budget determinism. *M2, M.*

3. **Append-only reflective memory that never mutates the canonical log.** [Reflexion]+[Generative-Agents]+[MemGPT]+[CoALA]. ## 4. Design tensions to decide deliberately

Each is a fork: the field default vs the consent-aligned choice, tied to the papers that raise it.

- **D1 — JSON tool schemas vs Lisp-first datums.** [MCP, Toolformer, Gorilla, AutoGen, tau-bench, CodeAct, Building-Effective-Agents]. *Field default:* JSON schemas *are* the model (args/results/envelopes are JSON). *Consent:* Lisp-first datums are canonical; JSON/MCP is a lowered projection. A JSON-Schema-subset→Scheme decoder is unavoidable surface area but lives strictly at the boundary as a one-way validated edge. The escaping-overhead win is provable (combo #10's fixture), not asserted. *Watch-item:* the decoder is where JSON can leak inward.

- **D2 — Free-form code execution vs capability-gated effects.** [CodeAct, AutoGen, Toolformer, Voyager, SWE-agent]. *Field default:* execute the model's code directly, sandbox after the fact; the action space *is* authority. *Consent:* the model's code is a proposal datum the loop READS and runs under policy, gated at sub-expression granularity (pause mid-form, resume live bindings). *Trade accepted:* the gated loop is slower and interruptible than a frictionless interpreter — bounded-untrusted-execution wins over loop speed.

- **D3 — Who authorizes completion/success: model self-evaluation vs deterministic verifier.** [ReAct, Reflexion, Voyager, ToT, SWE-bench, tau-bench, GAIA, Building-Effective-Agents]. *Field default:* the model (or model-as-judge) marks the verifier passed and the route authorized. *Consent:* model output PROPOSES; only a deterministic, policy-side verifier authorizes. `finish` ≠ `complete`; a critic's verdict is a proposal; the ToT evaluator is advisory; the GAIA "FINAL ANSWER" is a read datum; self-written tests are advisory evidence, never automatic completion. **The single most consent-distinctive rule; SWE-bench's held-out test patch is its canonical justification.**

- **D4 — Memory mutation vs append-only inspectable state.** [MemGPT, Generative-Agents, Reflexion, CoALA, Wang-survey, Voyager]. *Field default:* memory is mutable, lossy, ranked; eviction is deletion; reflection rewrites. *Consent:* the canonical store is append-only; the in-context working set is a rebuildable projection; reflection/consolidation are appended datums with `cites`/`supersedes`; eviction is a tombstone receipt; recency is an appended access event. *Sharpest sub-case:* procedural memory (the agent rewriting its own decision loop) — CoALA calls it unsolved; our answer (D2+D3) is gated, capability-inert, self-tested proposals.

- **D5 — Tree-search/backtracking vs deterministic single-track loop.** [ToT, Building-Effective-Agents, Wang-survey, AutoGen]. *Field default:* search is the control flow; backtracking silently discards subtrees; voting assumes cheap repeated calls. *Consent:* tree search is an opt-in, explicitly-budgeted planning sub-mode; the tree is append-only; `(backtrack …)` keeps the discarded subtree and accounts for grants it touched; true backtracking is sound only over pure-Scheme subtrees; voting is a deterministic Scheme function over recorded response datums. *Cost made first-class:* b·k·T folds into the allocation budget with a search-exhaustion receipt.

- **D6 — Autonomy locus: who drives the loop.** [MCP, MemGPT, AutoGen, tau-bench, Toolformer, Building-Effective-Agents]. *Field default:* the model/server/manager owns control flow; autonomy knobs are untracked kwargs; self-chaining capped by an implicit constant. *Consent:* the deterministic outer loop owns invocation/routing/eviction/termination; external initiation (MCP server-sampling, heartbeat self-chaining, speaker selection) is re-cast as a proposal the loop and gate own; `human_input_mode`/`max_consecutive_auto_reply` become policy-governed approval/budget data with receipts.

- **D7 — Determinism & cross-host parity vs the field's inherent nondeterminism.** [all — esp. multi-agent, embeddings, browsing, fine-tuning]. *Field default:* results are means over noisy runs on one implementation; learning lives in weights; retrieval lives in an opaque vector DB. *Consent:* all nondeterminism is quarantined to the model channel and recorded as fixed input on resync; embeddings are an untrusted advisory cache over a content-addressed store; live browsing → snapshotted evidence datums with the network capability an explicit grant; learning lives in append-only memory + content-addressed skills, never weights; logical clocks replace wall-clock. Anything that hashes/behaves differently across cores is a parity defect to fix at root, not assert away. This is also the *mechanical* version of GAIA's two-annotator agreement and tau-bench's uniqueness check.

## 5. SHORTLIST — the top 7 highest-leverage things to pursue, M2-first

Ordered. Each is scoped tightly enough to become a GitHub issue.

1. **Proposal-datum-never-eval'd: the code-action safety boundary.** [CodeAct]. The model emits a quoted form inside `(agent-action (kind code-action) …)`; the loop READS and walks it for capability requests and runs it under policy — never `eval`s raw model text as authority. Ship with a fixture where the proposed form tries to mint a grant / resolve an approval / call a host mutation directly, asserting the loop quarantines it to a `capability-decision`. **Why first:** without this the action space *is* authority and the entire stance collapses; everything else in the shortlist depends on it. *M2, M.*

2. **The non-proposable, policy-gated `verifier` capability, instantiated by the finish-split.** [SWE-bench], [ReAct], [Building-Effective-Agents], [Voyager], [GAIA]. Encode the FAIL_TO_PASS/PASS_TO_PASS partition (and quasi-exact-match for factoid tasks) as a policy-gated `verifier`; the model proposes `(action finish …)` but `complete` is reached only when the verifier stamps `verifier-passed`; a model form that self-asserts pass is rejected at the gate. **Why:** this is the eval-and-control-loop instantiation of the whole thesis (D3), and it makes SWE-bench/GAIA/evaluator-optimizer/Voyager-commit-on-verify all behave correctly under "the model never authorizes." *M2, M.*

3. **AST subtree verifier + three-way failure conditions.** [Gorilla], [tau-bench]. A proposed call is admitted only if it is a subtree of a registered capability signature; otherwise fail-closed with `hallucinated-tool` / `misapplied-tool` / `unauthorized-tool` receipts. **Why:** Gorilla's hardest mechanism is nearly free in a Lisp-first runtime (the proposed form *is* the AST), it is fail-closed, M2-now, and it gives the loop principled data-typed branch points for rejected calls. *M2, M (verifier) + S (split).*

4. **Docstring-metadata-derived tool specs.** [Toolformer], [Gorilla], [SWE-agent]. Generate the wire schema, the in-context example, and the capability gate's pure-vs-host decision from the existing `#((parameters)(returns)(effects))` metadata blocks. **Why:** it is the M2 native tool-calling deliverable, it eliminates schema/example/helper drift by construction, and the `effects` field wires the consent gate straight from the tool's own metadata — the cleanest possible demonstration of D1. *M2, M.*

5. **Mid-action budget-exhaustion parity fixture.** [CodeAct]. A fixture where an agent-emitted form contains an unbounded loop, asserting the allocation-charged step budget halts it with a `budget-exhausted` receipt pointing at the partial transcript, **byte-identical on both cores**. **Why:** it proves the two scariest constructs in the whole reference set — model-authored code as the action space, with unbounded loops — are bounded, gated, replayable, and cross-host-identical at once. This is the bounded-against-untrusted-code thesis (D2+D7) made undeniable, and it exercises the parity gate that is our signature claim. *M2, M.*

6. **Append-only gated reflection + deterministic retrieval with a selection receipt + memory classes.** [Reflexion], [Generative-Agents], [Wang-survey], [CoALA], [MemGPT]. One bundle: tag memory with a `memory-class` field; write `task-reflection`/synthesis datums only on `failed` receipts via a gated loop step with `(cites …)` edges; rank retrieval by an all-Scheme weighted sum emitting a `memory-selection` receipt; filter by scope and run redaction before any record enters a prompt. **Why:** memory is the largest cluster and the one with the sharpest unanimous tension (D4); this is where "append-only inspectable memory" becomes a demonstrable advantage over every framework in the set, and the retrieval/selection receipt + scope guard close a real leakage hole. *M2, M (full author behavior and paging defer to later).*

7. **pass^k decomposed by stop-receipt reason + two-tier policy ablation over a tau-bench fixture.** [tau-bench], [ReAct], [Building-Effective-Agents]. Rerun a fixture N times reseeding only model/user nondeterminism while holding policy/budgets/transitions fixed; report pass^k sliced by receipt reason; run the suite with the advisory policy tier in/out (gate-enforced authority rules are un-ablatable by definition) and report the pass^1 delta. **Why:** the single most compelling experiment in the set — it reproduces a SOTA benchmark, demonstrates the deterministic-loop separation of model flakiness from policy determinism that *only* this runtime can show, and converts tau-bench's central finding (agents ignore soft policy) into a structural guarantee. Entirely M2-now on stubbed providers. *M2, M.*

**Ordering rationale:** items 1–3 establish the non-bypassable spine (proposal-never-authority → verifier-never-proposable → structural admission gate); item 4 is the concrete M2 tool-calling deliverable that feeds 1 and 3; items 5–7 are the three flagship demonstrations (untrusted-code bounding, append-only memory advantage, reliability-and-policy benchmark) that turn the spine into results worth showing. Each is independently shippable in M2 once item 1 lands.
